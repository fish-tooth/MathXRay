# Demo 视频拍摄指引（≤120 秒）

面向课题 2 官方交付：**2 分钟以内展示一次完整的解题与过程评估流程**。

推荐成片 **110 秒**，分辨率 1920×1080，系统音量打开，浏览器全屏。不要口播未写入 `reports/official/` 的数字。

## 0. 开拍前准备（约 3 分钟，不进入成片）

1. 安装依赖并启动应用：

```bash
pip install -e .
streamlit run app.py
```

2. 浏览器打开本地地址（通常 `http://localhost:8501`），窗口最大化。
3. 左侧停在 **解题与审计**，输入方式选 **演示案例（推荐录屏）**。
4. 另开一个标签页备用：先点一次 **评测看板** 确认数字已加载（需已运行 `python scripts/aggregate_official.py`）。
5. 关闭无关通知；缩放 100%–110%，保证三张指标卡同屏。

若 Hy3 API 可用，可加录 10 秒「现场调用」作 B-roll，但**正片用演示案例**，避免超时。

## 1. 分镜脚本（110 秒）

录屏前请把「评估引擎」切到 **R1 反思式审查（推荐）**（默认即此项）。

| 时间 | 画面 | 口播 | 操作 |
|---|---|---|---|
| 0–12s | 解题页标题「不只看答案…」 | 「最终答案正确，并不代表推理过程正确。MathXRay 让 Hy3 解题，再用 R1 做四段审查。」 | 停留在标题，不要滚动 |
| 12–40s | 案例 1「过程成立 · 答案正确」 | 「第一步，R1 在看不到学生步骤的前提下独立求解，得到 50；与学生的 50 一致。逐段审查五个段落全部 VALID，因此不触发对抗轨。」 | 选择案例 1，缓慢滚过 ① 独立求解 与 ② 逐段审查 |
| 40–75s | 案例 2「定位最早错误」 | 「面积算成了 70，而独立求解得 60 —— 结论不一致，强制开启指控。符号证据在第 2 步锁定 12×5≠70，第 3 步只是传播错误。」 | 切到案例 2，鼠标停在 ③ 指控卡片约 3 秒 |
| 75–95s | 案例 3「答案正确 · 过程不成立」 | 「答案是 (3λ, −4λ)，与标准答案一致；但独立求解得到不同结论，指控成立：第 3 步遗漏 λ≠0。这就是 Unsupported Answer —— 答案碰巧对，过程撑不住结论。」 | 切到案例 3，指向橙色 Unsupported 横幅 |
| 95–115s | 评测看板 | 「在 ProcessBench 外部金标准上，首错定位准确率见看板；能力在竞赛难度开始明显下降。」 | 左侧切到「评测看板」，指向 M2 卡片与柱状图 |
| 115–120s | 回到标题或看板 | 「我们评估的不只是 Hy3 有没有算出答案，而是推理是否真的支撑这个答案。」 | 定格 2 秒后结束 |

英文收口（可选叠字幕）：

> We evaluate not only whether Hy3 reaches the answer, but whether its reasoning actually supports it.

## 2. 必须出现的画面清单

对照官方 R20 / M22：

- [ ] R1 ① 独立求解（私有脚手架，学生步骤不可见）
- [ ] R1 ② 逐段审查 VALID / INVALID / UNKNOWN（案例 1 全 VALID）
- [ ] R1 ③ 强制对抗：触发条件 + 指控 + 辩护（案例 2、3）
- [ ] R1 ④ 融合：最早错误步骤与错误类型
- [ ] `Final ✓ / Process ✗` 与 Unsupported 横幅（案例 3）
- [ ] 真实 benchmark 数字（看板 M2 / 分数据集柱状图）
- [ ] 成片 < 120s

> 三个 R1 案例由 `python scripts/prepare_demo_r1.py` 生成（`data/demo_cases_r1.json`），
> 用脚本化 mock 复现完整四段流程，不消耗 Hy3 配额，因此 402 也不影响录屏。

## 3. 录制建议

- Windows：Win+G（Xbox Game Bar）或 OBS，只录浏览器窗口。
- 口播可后期配音；若现场说，语速偏慢，数字读「零点七五」而不是一长串小数。
- 不要展示 `.env`、API Key、终端里的密钥。
- 导出 MP4（H.264）或 GIF。GIF 建议 10–12 fps、宽度 1280，以免文件过大。

## 4. 若录屏当天 API 不可用

正片**只使用三个演示案例 + 看板**。看板数字来自已冻结的 `reports/official/`。不要改用 mock 现场调用，以免评委看到 `"mock"`。
